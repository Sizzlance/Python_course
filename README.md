# University Python Projects Collection

Репозиторий содержит коллекцию скриптов и утилит, разработанных в рамках университетского курса по Python. Проекты охватывают широкий спектр задач: от системного администрирования и обработки данных до парсинга веб-страниц и реализации математических алгоритмов.
